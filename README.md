# 🏠 HomeFixerKhulna AI — v1.0.0

> Trusted Home and Commercial Service — Khulna, Bangladesh

## Quick Start

```bash
# 1. ডিপেন্ডেন্সি ইন্সটল
npm install

# 2. .env ফাইল সেটআপ
cp .env.example .env

# 3. সার্ভার চালু করুন
npm start
```
